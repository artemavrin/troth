# TROTH

Один мир на всех. Много Шепчущих. Каждое шептание оценивается моделью до оплаты:
метеорит стоит дороже, чем ссора королей.

## Документы

- [`docs/architecture.md`](docs/architecture.md) — архитектура 0.1: три вычислителя,
  ход мира, жизненный цикл шептания, ценообразование, демпфирование петли веры,
  схема данных, порядок сборки.
- [`docs/architecture-review.md`](docs/architecture-review.md) — проверка теорий: что
  подтвердилось снаружи, где не сходится арифметика и какие механизмы не выдержат
  нагрузки. Десять пунктов, два блокирующих.

## Состояние

Этап 0 — ещё не начат. Репозиторий пока содержит только проектные документы.
