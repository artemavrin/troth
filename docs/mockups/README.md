# Макеты

`quote.html` — предпросмотр котировки §5 рядом с ответом Jev, из которого он собран.
Открывается файлом в браузере, зависимостей нет. `quote.png` — снимок.

Слева — форма ответа `experimental_evaluate`, взятая **из типов** `ai@7.0.107` и
`@ai-sdk/gateway@4.0.87`, а не из документации. Числа в ней — макет: egress облачной
сессии закрыт политикой окружения, живого вызова не было.

Справа — предпросмотр из §5 плюс три правки разбора, помеченные рамкой:
- **`ожидание` показано до оплаты** — сейчас §5 его скрывает, хотя от него зависит,
  укрепится ли вера и вырастет ли репутация;
- **занятость слотов убеждений** в цене и в интерфейсе (пункт G: 32 — жёсткий потолок);
- **награда, обратная показанной вере** (пункт E: без неё «против течения» —
  доминируемая стратегия, разрыв ×200).
