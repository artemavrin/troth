# Карта и поле веры на vgpu

Настоящий прогон, не макет: сетка 512×512, шаг физики = 1 час мира, WGSL считается
headless на Dawn через `vgpu/node`. Тот же шейдер по §2 пойдёт в браузер — в этом и
была причина выбрать vgpu.

```bash
npm install vgpu playwright pngjs
node render.mjs        # симуляция + рендер → panel0..3.png, troth-map.png
node fig.mjs           # подписи и склейка → troth-belief.png
```

Результат: [`../../mockups/belief-spread.png`](../../mockups/belief-spread.png).

## Что здесь считается

`world.wgsl` — шаг 6 §3 (диффузия слухов) плюс самораспространение §6 выше порога 20%.
Слух смоделирован как **фронт реакции-диффузии**, а не как размазывание сохраняющейся
величины: первая попытка теряла 2% массы за шаг и за 2184 шага гасила веру в ноль.
Хребет держит молву (`pass_` по высоте), над водой слух не идёт (`land`).

`map.wgsl` — отмывка рельефа, вода, и поле веры поверх, с контурами на ступенях лестницы
§6. Кольца на карте — это пороги 20 / 40 / 60 / 80, а не украшение.

## Что прогон показал

Вброс сделан с верой Ember 91% — тем числом, которое §5 показывает в предпросмотре.

| событие | сутки мира |
|---|---|
| вера перешла 60% (локальные физические эффекты) | 1 |
| вера перешла 95% и стала **lore** | **40** |
| срок ожидания по §11 («дрожь земли до конца года») | 91 |

**Шептание стало вечной правдой мира за 51 день до того, как его предсказание проверили.**
Это независимое подтверждение B′ — теперь на пространственном поле, а не в закрытой
формуле. См. [`../../experiments-results.md`](../../experiments-results.md).
